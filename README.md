# 楊梅高中分機一覽表 - 互動式視覺化資訊網

本專案依據桃園市立楊梅高級中等學校（楊梅高中）校園分機一覽表設計，打造兼具現代美學、跨載具自適應響應式設計（手機、平板、電腦）、多維度即時檢索、高對比易讀排版與真實電話音效的互動式資訊網。

---

## 🌟 主要特色與功能

### 1. 📱 全載具響應式設計 (Responsive Design)
- **電腦版 (Desktop)**：大尺寸網格、詳細表格、多欄位校園館舍導覽視圖。
- **平板版 (Tablet)**：自適應卡片與直覺滑動觸控。
- **手機版 (Mobile)**：大按鈕快速點擊、大字體分機號碼、一鍵喚起手機原生通話（支援自動暫停撥分機語法 `tel:034789618,分機`）。

### 2. 🔍 強大即時檢索與多維度篩選
- **即時智慧搜尋**：鍵入分機號碼（如 `1201`）、處室（如 `教務`）、職稱（如 `組長`、`護理師`）、姓名或業務職掌關鍵字，即時過濾並**黃色高亮標記**符合文字。
- **快速鍵支援**：按下鍵盤 `/` 或 `Ctrl+K` 即可秒速跳轉至搜尋框；`Esc` 清除。
- **處室分類標籤**：全部、校長室及幕僚、教務處、學務處/教官室、總務處、輔導室、圖書館、實習處/專科、教師辦公室/導師室、專科教室及設施。
- **校園館舍篩選**：行政大樓、蘊慧樓、日新樓、懷德樓、弘道樓、圖資大樓、體育館、校門大門。
- **多元排序**：依分機號碼小到大/大到小、依處室筆劃、常用分機優先。

### 3. 🔤 閱讀友善與字體放大功能（高對比、不傷眼）
- 基準字體設定為 16px 起跳，分機號碼以 **28px~36px 醒目等寬字體** 呈現，一目了然。
- 內建 **字體切換功能**：支援「標準 A (16px)」、「加大 A+ (18px)」、「特大 A++ (20px)」，對長輩、師長或手機使用者格外友善。

### 4. 🎨 明亮豐富的視覺化與動畫
- 活潑明亮的學院風漸層與處室專屬色彩標籤（藍、綠、橘、紫、青）。
- 重要緊急據點（如警衛室 1110、健康中心 1119/1342、24H 校安值勤 1353）配備 **呼吸發光動畫 (Pulsing Glow)**。
- 卡片懸浮微互動（Hover Lift）、流暢淡入與滑動彈窗。

### 5. 🔊 真實雙音多頻 (DTMF) 電話音效與高互動性
- **零外部依賴 Web Audio API**：載入即響、零延遲、離線亦可正常運作。
- **真實電話撥號音 (DTMF)**：1~9、0、*、# 每一鍵皆合成真實國際標準音頻。
- **虛擬電話撥號模擬器**：可點擊號碼體驗模擬撥號、回鈴音（嘟--嘟--）至通話接通流程。
- **音效回饋**：點擊音、星號收藏音、複製成功叮聲、音效開關（🔊/🔇）記憶於瀏覽器中。

### 6. ⭐ 常用分機與實用工具
- **星號收藏**：點擊每張卡片或列表的星號即可加入常用，並支援「只看常用」。
- **一鍵複製**：複製 4 碼分機或完整總機撥號字串。
- **常見問題快速找人指南 (FAQ)**：身體不適、請假遲到、成績單補發、心理諮商、水電報修、WiFi 密碼等情境一鍵篩選。
- **A4 美編列印**：內建 Print CSS，點擊「列印表單」即可產出乾淨整齊的紙本分機表。
- **自訂/PDF 文字匯入器**：可隨時貼上新版 PDF 文字或 JSON 更新分機資料庫。

## 📂 專案檔案架構

| 檔案名稱 | 說明 |
| :--- | :--- |
| **`index.html`** | 網站主頁面，語意化 HTML5 架構、包含頂部導覽、Hero、搜尋面板、三種視圖與撥號 Modal |
| **`styles.css`** | 視覺樣式表，包含全自適應排版、字級切換、色彩系統、動畫特效與列印專用樣式 |
| **`data.js`** | 楊梅高中各處室完整分機資料庫、分類定義、校園館舍資料與常見導引問答 |
| **`sound.js`** | Web Audio API 聲音引擎，提供 DTMF 電話音頻合成、回鈴音與介面音效 |
| **`app.js`** | 主互動程式，負責即時檢索、高亮、篩選排序、收藏夾、通話撥號與匯入邏輯 |

---

## 🚀 如何開啟使用

直接使用瀏覽器（Google Chrome、Microsoft Edge、Safari 或 Firefox）雙擊開啟 **`index.html`** 即可立即體驗！無需安裝任何伺服器或額外套件。
